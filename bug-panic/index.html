📁 COMO COLOCAR OS JOGOS NO GITHUB PAGES

Para o Portal e os Jogos funcionarem juntos no mesmo link do GitHub Pages, deixe o repositório exatamente assim (tudo em minúsculas, sem espaços):

📁 seu-repositorio
├── 📄 index.html ← (Portal Games Apolo)
├── 📁 tinywings └ 📄 index.html (1º jogo)
├── 📁 tinybomb └ 📄 index.html (2º jogo)
├── 📁 zabble └ 📄 index.html (3º jogo)
└── 📁 bugpanic └ 📄 index.html (4º jogo)
